# Release policy

The owner explicitly authorized MIT for owned material and public publication on 18 October 2026. The [release review](RELEASE-REVIEW.md) records the checked publication scope. This package contains no script that changes repository visibility.

Maintain these boundaries for future releases:

1. Keep customer instructions, design decisions, private references and captures in their projects. Do not publish original exports, private benchmark evidence, source-project history or installer backups.
2. Preserve the MIT notices for owned material and the [attribution inventory](ATTRIBUTION.md). Original-template redistribution rights remain unestablished; that material stays excluded. Official integrations and skills remain dependencies.
3. Run `python3 -m unittest discover -s tests -v` and `python3 scripts/check_package.py --require-noreply`. Inspect the actual files, staged diff, commit messages/metadata and all reachable history. Automated guards are not exhaustive privacy or rights clearance.
4. Review hosted branches, tags, issues, releases, comments, workflow logs and artifacts before publication; files outside Git can also expose private material.
5. Keep documentation aligned with observed capability. Do not claim original model/template parity, guaranteed design quality or access to every Figma file.

The generic example is fictional and contains no Figma destination or customer asset. Account connections use supported authentication outside this repository. Publication grants no rights to excluded material and does not make private design approval an implementation approval.
